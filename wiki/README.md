# wiki

Project knowledge for liquidglass: specs, research, plans and decisions. It is written for
whoever maintains the project next, human or agent.

- `research/` holds sources and what was learned from them.
- `plans/` holds implementation plans, one file per plan, when there is work to plan.

Add a subdirectory when the first page for it appears, and link new pages from here.

## Pages

- [research/liquid-glass-reference.md](research/liquid-glass-reference.md) is the video spec the material and its defaults were built from.
